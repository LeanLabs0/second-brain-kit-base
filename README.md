# OS Kit Base

A starter kit that turns a coding agent (Claude Code, Gemini, Codex) into a personal AI operating system: context files, a connections registry, a decisions log, and three skills (onboard, audit, level-up).

De-branded internal base, kept as reference material and as a candidate skeleton for client installs.

## Layout

- `CLAUDE.md` : operating-manual template with placeholders, filled by /onboard
- `aios-intake.md` : the 7-question intake contract; edit and re-run onboard any time
- `context/` : about you, your business, your priorities
- `connections.md` : registry of every system the OS can reach
- `references/operator-framework.md` : the operator thinking framework (mindset, method, machine)
- `decisions/log.md` : append-only decision record
- `archives/` : old files; move, never delete
- `.claude/skills/` : onboard, audit, level-up
